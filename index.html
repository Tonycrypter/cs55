How placeholders work

Values update matching commands and copies locally; nothing is saved or sent. DC also fills DNS server; domain fills LDAP base DN. Ports, users, pivot hosts, and other placeholders stay manual. IPv6 is not supported by these templates.

A DC IP does not infer its TLS hostname; DNS options requiring a literal IP stay manual when the DC is a hostname. A target FQDN fills hostname templates but leaves the IP in curl --resolve for you to supply.
