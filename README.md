# CS55 — OSCP Cheatsheet

**Made by [Tonycrypter](https://github.com/Tonycrypter), with ADHD-friendly focus in mind.**

A simple OSCP preparation reference designed to reduce clutter and help you
focus on **one command or one next check at a time**.

## [Open the website](https://tonycrypter.github.io/cs55/)

### What you get

- Search commands by tool, service, or task.
- Read what a command does and copy it.
- Follow **Finding → next check** when you feel stuck.
- Browse one entry at a time with **Previous / Next**.
- Larger text, collapsible notes, and dark/light themes.
- Green commands, red targets, and orange username/password placeholders.
- No timers, auto-advance, ads, or runtime AI.

### How to use

1. Search for a tool or choose a service.
2. Select a stage, such as **Enumeration** or **Troubleshooting**.
3. Read the command and its notes.
4. Replace remaining `<PLACEHOLDERS>` before use.

The page never runs commands. Reading positions stay only while the page is open.
For offline use, download the repository and open [index.html](./index.html).

### Update the website

Edit your cloned repository in VS Code, then:
**Source Control → Stage changes → Commit → Sync Changes**.
GitHub Pages redeploys after you push to its publishing branch.
Saving a file alone does not publish it.

### Important

Use only in authorized labs or assessments. This is independent study material,
not OffSec-approved guidance or a guarantee of exam compliance. Check the current
[exam rules](https://help.offsec.com/hc/en-us/articles/360040165632-OSCP-Exam-Guide)
and verify commands against your installed tool version. Templates are not
target-tested. Never publish credentials, exam evidence, or private notes.
